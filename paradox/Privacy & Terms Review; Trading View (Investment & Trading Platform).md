# WHAT INFORMATION IS COLLECTED BY TRADING VIEW

Users can browse aspects of the Trading View website without creating an account, where a user opts to create an account, trading view will collect;

* Username  
* Email address  
* Account information for social internet services (Facebook, X/Twitter, Google, Yahoo, Linkedin, Apple) (optional)  
* If purchasing a subscription;  
  * First name  
  * Last name  
  * Postal Address  
  * Payment information (payment card, bank account information, or payment account information).  
* Phone number  
* Avatar image / profile picture  
* Date joined  
* IP Address  
* Browser style  
* Internet Service Provider  
* Referring pages  
* Exit pages  
* Platform type  
* Device Type  
* Operating System  
* Application version  
* Browser version  
* Google Advertising ID or other advertising identifier  
* If signing into an account using internet service credentials (Facebook, Twitter/X, Google, Yahoo, LinkedIn, Apple), such service sends Trading View the username and email address associated with the credentials used.

Trading View does not require users to ID verify to use the platform for using their basic features, however to undertake trades the user is required to undergo KYC with the third-party broker.

# DATA RETENTION

If a user requests to delete an account, the account will be deleted after 30 days, during which the user can stop the deletion process.

Where an account is deleted, published ideas/scripts and messages sent to other users will be saved “as they have already integrated into our system”.

Certain data including but not limited to; transaction logs, financial records, addresses and employment details may be kept for up to ten (10) years to comply with legal obligations including tax laws, audits and security.

Published ideas will remain on the site and messages sent to other users cannot be deleted even in the instance of account deletion.
